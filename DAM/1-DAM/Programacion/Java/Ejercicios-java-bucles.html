Ejercicio 1 — Números pares menores de 100

Programa que visualice los números pares menores de 100.

Pista: Parte del primer par (2) y súmale 2 en cada vuelta. El bucle while debe repetirse mientras el número siga siendo menor que 100.

Entrada

Ninguna

Salida

Los pares del 2 al 98

import java.util.Scanner;

public class ParesMenores100 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int num = 2;

        while (num < 100) {
            System.out.println(num);
            num += 2;
        }

        sc.close();
    }
}

Lógica: se usa un contador que arranca en el primer par y avanza de 2 en 2, así nunca hace falta comprobar si es par. La condición de fin es num < 100. Se empieza en 2 al entender que el 0 no interesa; si lo quieres incluir, inicializa num a 0.

Ejercicio 2 — Suma de los 10 primeros enteros

Programa que realice la suma de los 10 primeros números enteros.

Pista: Necesitas dos variables: un contador que vaya de 1 a 10 y un acumulador que parta de 0 y vaya sumando el contador en cada vuelta.

Entrada

Ninguna

Salida

suma (resultado: 55)

import java.util.Scanner;

public class SumaDiezPrimeros {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int suma = 0;
        int contador = 1;

        while (contador <= 10) {
            suma += contador;
            contador++;
        }

        System.out.println("La suma de los 10 primeros enteros es: " + suma);

        sc.close();
    }
}

Lógica: patrón clásico contador + acumulador. El acumulador se inicializa a 0 (elemento neutro de la suma) antes del bucle, y el contador se incrementa dentro para garantizar que el bucle termina.

Ejercicio 3 — Impares entre N1 y N2

Visualizar todos los impares comprendidos entre N1 y N2, siendo N1 y N2 dos números cuya introducción se solicita por teclado.

Pista: Antes del bucle, calcula el primer impar a partir de N1: si N1 ya es impar te sirve, y si es par, el siguiente es N1 + 1. Después avanza de 2 en 2 hasta pasar de N2. Un número es impar si num % 2 != 0.

Entrada

n1, n2 (por teclado)

Salida

Los impares entre n1 y n2

import java.util.Scanner;

public class ImparesEntre {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce N1: ");
        int n1 = sc.nextInt();
        System.out.print("Introduce N2: ");
        int n2 = sc.nextInt();

        int impar;
        if (n1 % 2 != 0) {
            impar = n1;
        } else {
            impar = n1 + 1;
        }

        while (impar <= n2) {
            System.out.println(impar);
            impar += 2;
        }

        sc.close();
    }
}

Lógica: se ajusta el punto de partida para que sea impar y a partir de ahí se salta de 2 en 2, evitando comprobar la paridad en cada vuelta. Los extremos se incluyen si son impares. Si n2 < n1 el bucle no se ejecuta ninguna vez (es lo que corregirá el ejercicio siguiente).

Ejercicio 4 — Forzar que N2 ≥ N1

Modificar el programa anterior para obligar a que N2 sea igual o mayor a N1.

Pista: Es una validación de entrada: hay que pedir N2 al menos una vez y repetir la petición mientras sea menor que N1. Eso es justo lo que hace un do-while.

Entrada

n1, n2 (con n2 >= n1)

Salida

Los impares entre n1 y n2

import java.util.Scanner;

public class ImparesEntreValidado {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce N1: ");
        int n1 = sc.nextInt();
        int n2;

        do {
            System.out.print("Introduce N2 (mayor o igual que N1): ");
            n2 = sc.nextInt();
            if (n2 < n1) {
                System.out.println("Error: N2 debe ser mayor o igual que N1");
            }
        } while (n2 < n1);

        int impar = (n1 % 2 != 0) ? n1 : n1 + 1;

        while (impar <= n2) {
            System.out.println(impar);
            impar += 2;
        }

        sc.close();
    }
}

Lógica: el do-while es el bucle ideal para validar entradas porque el dato se pide siempre al menos una vez y la condición se comprueba después. Se declara n2 fuera del bucle para poder usarla en la condición. El operador ternario (cond) ? a : b sustituye al if-else del ejercicio anterior.

Ejercicio 5 — Repetir hasta que N1 y N2 sean 0

Además, este proceso se debe repetir una y otra vez. Finalizaremos cuando tanto N1 como N2 sean 0.

Pista: Mete todo el programa anterior dentro de un bucle exterior do-while. La condición para seguir es la negación de "ambos son 0": n1 != 0 || n2 != 0.

Entrada

n1, n2 en cada ronda

Salida

Los impares de cada ronda, hasta introducir 0 y 0

import java.util.Scanner;

public class ImparesRepetido {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n1, n2;

        do {
            System.out.print("Introduce N1: ");
            n1 = sc.nextInt();

            do {
                System.out.print("Introduce N2 (mayor o igual que N1): ");
                n2 = sc.nextInt();
                if (n2 < n1) {
                    System.out.println("Error: N2 debe ser mayor o igual que N1");
                }
            } while (n2 < n1);

            int impar = (n1 % 2 != 0) ? n1 : n1 + 1;
            while (impar <= n2) {
                System.out.println(impar);
                impar += 2;
            }
        } while (n1 != 0 || n2 != 0);

        sc.close();
    }
}

Lógica: bucles anidados: el exterior controla las rondas y el interior valida N2. Por la ley de De Morgan, "terminar cuando n1 = 0 y n2 = 0" equivale a "continuar mientras n1 ≠ 0 o n2 ≠ 0". Las variables n1 y n2 se declaran antes del bucle exterior porque se leen en su condición.

Ejercicio 6 — Mínimo y media de una serie

Pedir la introducción de una serie de valores por teclado. Se deberá visualizar el valor mínimo y la media. El criterio para dejar de introducir valores será que se responda N (no) a la pregunta “¿Desea continuar introduciendo valores?”.

Pista: Mantén tres variables: suma, cantidad y minimo. El mínimo no se puede inicializar a 0 (sería un valor falso si todos son positivos): asígnaselo con el primer valor leído.

Entrada

Valores (por teclado) y respuesta S/N

Salida

minimo y media

import java.util.Scanner;

public class MinimoYMedia {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        double valor, minimo = 0, suma = 0;
        int cantidad = 0;
        String respuesta;

        do {
            System.out.print("Introduce un valor: ");
            valor = sc.nextDouble();

            if (cantidad == 0 || valor < minimo) {
                minimo = valor;
            }
            suma += valor;
            cantidad++;

            System.out.print("¿Desea continuar introduciendo valores? (S/N): ");
            respuesta = sc.next();
        } while (!respuesta.equalsIgnoreCase("N"));

        double media = suma / cantidad;

        System.out.println("Valor mínimo: " + minimo);
        System.out.println("Media: " + media);

        sc.close();
    }
}

Lógica: bucle controlado por una respuesta del usuario. La condición cantidad == 0 hace que el primer valor se convierta en el mínimo inicial. La media es suma / cantidad y es seguro dividir porque el do-while garantiza al menos un valor. Las cadenas se comparan con equalsIgnoreCase(), nunca con ==.

Ejercicio 7 — Sumatorio con doble condición de fin

Pedir la introducción de una serie de valores por teclado. Para cada uno de ellos se deberá visualizar su sumatorio. El criterio para dejar de introducir valores será o bien que ya hayamos introducido 20 o bien que el último sumatorio calculado sea mayor a 300.

Pista: Hay dos razones para parar, pero el bucle se escribe con la condición para continuar, que debe cumplir ambas a la vez: todavía no van 20 valores y la suma aún no supera 300.

Entrada

Valores (por teclado)

Salida

Sumatorio acumulado tras cada valor

import java.util.Scanner;

public class SumatorioLimite {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        double valor, suma = 0;
        int contador = 0;

        do {
            System.out.print("Introduce un valor: ");
            valor = sc.nextDouble();
            suma += valor;
            contador++;
            System.out.println("Sumatorio actual: " + suma);
        } while (contador < 20 && suma <= 300);

        System.out.println("Fin: " + contador + " valores introducidos, sumatorio " + suma);

        sc.close();
    }
}

Lógica: las condiciones de fin se combinan con O (basta una), así que la condición de continuación las niega y las une con &&: !(contador == 20 || suma > 300) es lo mismo que contador < 20 && suma <= 300.

Ejercicio 8 — Valores entre 5 y 100

Modificar el programa anterior para obligar a que los números que se introduzcan por teclado estén comprendidos entre 5 y 100. En caso de introducirse algún valor erróneo (-20, 0, 140, etc), se visualizará el mensaje “Valor erróneo” y se pedirá repetitivamente otro valor hasta que éste sea válido.

Pista: Añade un do-while interior que sustituya a la lectura simple del valor. Se repite mientras el valor sea menor que 5 o mayor que 100. El bucle exterior no cambia.

Entrada

Valores entre 5 y 100 (por teclado)

Salida

Sumatorio tras cada valor válido

import java.util.Scanner;

public class SumatorioValidado {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        double valor, suma = 0;
        int contador = 0;

        do {
            do {
                System.out.print("Introduce un valor (5-100): ");
                valor = sc.nextDouble();
                if (valor < 5 || valor > 100) {
                    System.out.println("Valor erróneo");
                }
            } while (valor < 5 || valor > 100);

            suma += valor;
            contador++;
            System.out.println("Sumatorio actual: " + suma);
        } while (contador < 20 && suma <= 300);

        System.out.println("Fin: " + contador + " valores introducidos, sumatorio " + suma);

        sc.close();
    }
}

Lógica: el patrón "leer con validación" (do-while interior) se encaja dentro del bucle del ejercicio anterior sin modificarlo. Los valores erróneos no incrementan el contador ni se suman, porque solo se sale del bucle interior cuando el dato ya es válido.

Ejercicio 9 — Contar las aes

Pedir que se introduzcan caracteres por teclado ($ para terminar) y visualizar el número de aes introducidas (mayúsculas o minúsculas).

Pista: Lee los caracteres con sc.next().charAt(0). Para no escribir dos comparaciones, pasa el carácter a minúscula con Character.toLowerCase() antes de comparar con 'a'. El bucle termina al leer '$'.

Entrada

Caracteres (por teclado), $ para terminar

Salida

contA (número de aes)

import java.util.Scanner;

public class ContarAes {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        char caracter;
        int contA = 0;

        do {
            System.out.print("Introduce un carácter ($ para terminar): ");
            caracter = sc.next().charAt(0);

            if (Character.toLowerCase(caracter) == 'a') {
                contA++;
            }
        } while (caracter != '$');

        System.out.println("Número de aes introducidas: " + contA);

        sc.close();
    }
}

Lógica: bucle con centinela ($): un valor especial que indica el final y no forma parte de los datos. Los char se comparan con == y comillas simples. El $ no se confunde con una 'a', así que no altera la cuenta.

Ejercicio 10 — Pesos hasta superar 200 kg

Programa que pida la introducción de pesos, hasta que la suma supere los 200 Kg.

Pista: Acumula cada peso en una variable. Mientras la suma sea menor o igual que 200 hay que seguir pidiendo (cuidado: "supere" significa estrictamente mayor).

Entrada

Pesos en kg (por teclado)

Salida

total acumulado

import java.util.Scanner;

public class PesosLimite {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        double peso, total = 0;

        do {
            System.out.print("Introduce un peso (kg): ");
            peso = sc.nextDouble();

Lógica: acumulador con condición de fin sobre el propio acumulador. Se usa do-while porque hay que pedir al menos un peso. La condición para seguir es total <= 200: el bucle termina en cuanto total > 200.

Ejercicio 11 — Pares e impares hasta introducir 0

Aceptar números por teclado hasta que se introduzca un 0 y visualizar cuántos pares e impares se han introducido en la secuencia. Hacerlo con mientras y con repetir.

Pista: Con while tienes que leer un primer número antes del bucle y volver a leer al final de cada vuelta. Con do-while basta una lectura dentro, pero ojo: el 0 final no debe contarse como par.

Entrada

Números enteros (por teclado), 0 para terminar

Salida

pares e impares

Versión con while

import java.util.Scanner;

public class ParesImparesWhile {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int num, pares = 0, impares = 0;

        System.out.print("Introduce un número (0 para terminar): ");
        num = sc.nextInt();

        while (num != 0) {
            if (num % 2 == 0) {
                pares++;
            } else {
                impares++;
            }
            System.out.print("Introduce un número (0 para terminar): ");
            num = sc.nextInt();
        }

        System.out.println("Pares: " + pares);
        System.out.println("Impares: " + impares);

        sc.close();
    }
}

Versión con do-while

import java.util.Scanner;

public class ParesImparesDoWhile {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int num, pares = 0, impares = 0;

        do {
            System.out.print("Introduce un número (0 para terminar): ");
            num = sc.nextInt();

            if (num != 0) {
                if (num % 2 == 0) {
                    pares++;
                } else {
                    impares++;
                }
            }
        } while (num != 0);

        System.out.println("Pares: " + pares);
        System.out.println("Impares: " + impares);

        sc.close();
    }
}

Lógica: con while la condición se evalúa antes, por eso se necesita una lectura previa (cebado) y otra al final del cuerpo. Con do-while se evalúa después, así que la lectura va dentro, pero hay que proteger el 0 con if (num != 0). Ambas versiones dan el mismo resultado.

Ejercicio 12 — Factorial de un número

Calcular el factorial del número introducido por teclado.

Pista: n! = 1 · 2 · 3 · … · n. Usa un acumulador que parta de 1 (no de 0, o todo daría 0) y multiplícalo por un contador que vaya de 2 a n. Recuerda que 0! = 1 y que los negativos no tienen factorial.

Entrada

n (por teclado)

Salida

factorial de n

import java.util.Scanner;

public class Factorial {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce un número: ");
        int n = sc.nextInt();

        if (n < 0) {
            System.out.println("Error: el factorial no está definido para negativos");
        } else {
            long factorial = 1;
            int i = 2;

            while (i <= n) {
                factorial *= i;
                i++;
            }

            System.out.println(n + "! = " + factorial);
        }

        sc.close();
    }
}

Lógica: acumulador multiplicativo, inicializado a 1 (elemento neutro del producto). Para n = 0 y n = 1 el bucle no se ejecuta y se obtiene 1, que es correcto. Se usa long porque el factorial crece muy rápido: con int se desborda a partir de 13!, y con long a partir de 21!.

Ejercicio 13 — Adivina el número

Pedir un número por teclado que habrá que adivinar posteriormente de la siguiente forma: se leerán números hasta que uno sea igual al número a adivinar o hasta que se alcancen 5 intentos. Mientras no se adivine el número habrá que visualizar “El número a adivinar es mayor (o menor) que el que acabas de introducir”. Finalmente, escribir la cantidad de intentos en que se adivinó el número.

Pista: El bucle tiene dos condiciones de fin: acertar o llegar a 5 intentos. Usa una variable booleana acertado y un contador intentos. Al salir, comprueba acertado para saber por cuál de las dos razones terminó.

Entrada

secreto y los intentos (por teclado)

Salida

Pistas mayor/menor y número de intentos

import java.util.Scanner;

public class AdivinaNumero {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Jugador 1, introduce el número a adivinar: ");
        int secreto = sc.nextInt();

        int intento, intentos = 0;
        boolean acertado = false;

        do {
            System.out.print("Jugador 2, introduce un número: ");
            intento = sc.nextInt();
            intentos++;

            if (intento == secreto) {
                acertado = true;
            } else if (secreto > intento) {
                System.out.println("El número a adivinar es mayor que el que acabas de introducir");
            } else {
                System.out.println("El número a adivinar es menor que el que acabas de introducir");
            }
        } while (!acertado && intentos < 5);

        if (acertado) {
            System.out.println("¡Acertaste en " + intentos + " intentos!");
        } else {
            System.out.println("Has agotado los 5 intentos. El número era " + secreto);
        }

        sc.close();
    }
}

Lógica: usa una bandera booleana (acertado) para recordar por qué terminó el bucle. La condición de continuación !acertado && intentos < 5 es la negación de "acertó o se acabaron los intentos". Las pistas solo se muestran en la rama de fallo.

Ejercicio 14 — N primeros divisores de M

Generar los N primeros divisores de M.

Pista: Prueba candidatos desde 1 en adelante: un número d divide a M si M % d == 0. Cuenta cuántos divisores llevas encontrados y para al llegar a N. Pero ojo, ¿qué pasa si M tiene menos de N divisores? Limita también el candidato a M.

Entrada

n, m (por teclado)

Salida

Los n primeros divisores de m

import java.util.Scanner;

public class PrimerosDivisores {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("¿Cuántos divisores quieres (N)? ");
        int n = sc.nextInt();
        System.out.print("Introduce M: ");
        int m = sc.nextInt();

        int candidato = 1;
        int encontrados = 0;

        while (encontrados < n && candidato <= m) {
            if (m % candidato == 0) {
                System.out.println(candidato);
                encontrados++;
            }
            candidato++;
        }

        if (encontrados < n) {
            System.out.println("M solo tiene " + encontrados + " divisores");
        }

        sc.close();
    }
}

Lógica: se recorren los candidatos de 1 a M y se cuenta cada divisor hallado. El bucle tiene de nuevo dos condiciones de fin: ya se encontraron N divisores, o ya no quedan candidatos (candidato > m). Sin la segunda, un valor de N demasiado grande causaría un bucle infinito. Se asume m > 0; con m = 0 el bucle no se ejecuta.

Ejercicio 15 — Número perfecto

Programa que nos diga si el número introducido es perfecto (un número es perfecto si es igual a la suma de sus divisores propios). Ejemplos: 6 (1+2+3), 28 (1+2+4+7+14); 496 y 8128 son los siguientes en la lista.

Pista: Recorre los posibles divisores desde 1 hasta num / 2 (ningún divisor propio puede ser mayor que la mitad), acumula los que dividan exactamente y, al terminar, compara la suma con el número. Los divisores no incluyen al propio número.

Entrada

num (por teclado)

Salida

Mensaje: es perfecto / no es perfecto

import java.util.Scanner;

public class NumeroPerfecto {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce un número: ");
        int num = sc.nextInt();

        int suma = 0;
        int divisor = 1;

        while (divisor <= num / 2) {
            if (num % divisor == 0) {
                suma += divisor;
            }
            divisor++;
        }

        if (num > 0 && suma == num) {
            System.out.println(num + " es un número perfecto");
        } else {
            System.out.println(num + " no es un número perfecto");
        }

        sc.close();
    }
}

Lógica: se acumulan los divisores propios (todos menos el propio número) recorriendo hasta num / 2. Si la suma coincide con el número, es perfecto. La comprobación num > 0 evita que 0 pase como perfecto (su suma sería 0). Prueba con 6, 28, 496 y 8128.
