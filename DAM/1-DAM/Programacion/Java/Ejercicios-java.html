Ejercicio 1 — Valor absoluto de un número

Leer un número y escribir el valor absoluto del mismo.

Pista: piensa en el signo del número. Con una única estructura if-else puedes decidir si hay que cambiarle el signo o dejarlo tal cual.

Entrada

num (número real introducido por teclado)

Salida

abs (valor absoluto de num)

import java.util.Scanner;

public class ValorAbsoluto {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce un número: ");
        double num = sc.nextDouble();
        double abs;

        if (num < 0) {
            abs = -num;
        } else {
            abs = num;
        }

        System.out.println("El valor absoluto es: " + abs);
        sc.close();
    }
}

Lógica: es la estructura selectiva más simple. Si num es negativo, se invierte su signo con -num; si ya es positivo o cero, se deja igual. La condición num < 0 es el único punto de decisión del algoritmo.

Ejercicio 3 — Hipotenusa de un triángulo rectángulo

Calcula la hipotenusa de un triángulo rectángulo conocidas las longitudes de los catetos.

Pista: recuerda el teorema de Pitágoras (hip² = cat1² + cat2²) y usa Math.sqrt() para la raíz cuadrada y Math.pow() para elevar al cuadrado.

Entrada

cat1, cat2 (longitudes de los catetos)

Salida

hip (longitud de la hipotenusa)

import java.util.Scanner;

public class Hipotenusa {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce el primer cateto: ");
        double cat1 = sc.nextDouble();
        System.out.print("Introduce el segundo cateto: ");
        double cat2 = sc.nextDouble();

        double hip = Math.sqrt(Math.pow(cat1, 2) + Math.pow(cat2, 2));

        System.out.println("La hipotenusa mide: " + hip);
        sc.close();
    }
}

Lógica: aplica el teorema de Pitágoras usando Math.sqrt() y Math.pow() de la clase Math. No requiere estructura selectiva, es secuencial.

Ejercicio 4 — Porcentaje de hombres y mujeres

Pedir por teclado el número de hombres y número de mujeres que hay en un grupo de estudiantes. Visualizar el porcentaje de hombres y mujeres del total.

Pista: calcula primero el total de estudiantes (hombres + mujeres) y guárdalo en una variable; luego aplica una regla de tres a cada grupo.

Entrada

hombres, mujeres (por teclado)

Salida

porcHombres, porcMujeres (%)

import java.util.Scanner;

public class PorcentajeGenero {

Ejercicio 9 — Ecuación de segundo grado

Resolver la ecuación cuadrática ax²+bx+c=0. Si la operación dentro de la raíz es inferior a 0, visualizar "La solución son dos números complejos conjugados". Si el divisor es 0, visualizar "Error: División entre 0".

Pista: primero comprueba si a = 0 (evita dividir entre 0). Después calcula el discriminante (b² - 4ac) en una variable intermedia y decide según su signo antes de aplicar Math.sqrt(). Compara con ==, no con =.

Entrada

a, b, c (coeficientes)

Salida

x1, x2 o mensaje de error / complejas

import java.util.Scanner;

public class EcuacionCuadratica {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce el coeficiente a: ");
        double a = sc.nextDouble();
        System.out.print("Introduce el coeficiente b: ");
        double b = sc.nextDouble();
        System.out.print("Introduce el coeficiente c: ");
        double c = sc.nextDouble();

        if (a == 0) {
            System.out.println("Error: División entre 0");
        } else {
            double discriminante = Math.pow(b, 2) - 4 * a * c;

            if (discriminante < 0) {
                System.out.println("La solución son dos números complejos conjugados");
            } else {
                double x1 = (-b + Math.sqrt(discriminante)) / (2 * a);
                double x2 = (-b - Math.sqrt(discriminante)) / (2 * a);
                System.out.println("x1 = " + x1);
                System.out.println("x2 = " + x2);
            }
        }
        sc.close();
    }
}

Lógica: usa selectivas anidadas. La primera comprueba que a no sea 0 (con ==) (evita dividir entre 0 en la fórmula). La segunda, ya dentro, evalúa el discriminante: si es negativo no existe raíz real (soluciones complejas); si es ≥ 0 se calculan x1 y x2 con la fórmula general, usando discriminante como variable intermedia para no repetir el cálculo.

Ejercicio 10 — Día de la semana

Programa que permita ingresar un número de 1 a 7 y visualice el correspondiente día de la semana (1 Lunes, 2 Martes, etc). Si el número introducido no está comprendido entre 1 y 7 visualizar "Error: valor fuera de rango".

Pista: con siete valores concretos que comparar sobre la misma variable, la estructura switch es más clara que encadenar siete if. No olvides el break de cada caso ni el caso default.

Entrada

dia (número entero 1-7)

Salida

Nombre del día o mensaje de error

import java.util.Scanner;

public class DiaSemana {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce un número del 1 al 7: ");
        int dia = sc.nextInt();

        switch (dia) {
            case 1: System.out.println("Lunes"); break;
            case 2: System.out.println("Martes"); break;
            case 3: System.out.println("Miércoles"); break;
            case 4: System.out.println("Jueves"); break;
            case 5: System.out.println("Viernes"); break;
            case 6: System.out.println("Sábado"); break;
            case 7: System.out.println("Domingo"); break;
            default:
                System.out.println("Error: valor fuera de rango");
        }
        sc.close();
    }
}

Lógica: en lugar de encadenar siete if-else, se usa la estructura selectiva múltiple switch, ideal cuando una misma variable se compara con varios valores concretos. La cláusula default cubre cualquier valor fuera de 1-7, y cada break evita que Java siga ejecutando los casos siguientes.

Ejercicio 11 — Área de círculo o rectángulo

Programa que calcule el área, bien de un círculo, bien de un rectángulo. Pedirá que se introduzca C o R. Si se introdujo C, pedir el radio y visualizar área. Si se introdujo R, pedir base y altura y visualizar área.

Pista: primero decide qué figura es (compara con 'C' o 'R', usando == porque es un char) y, dentro de cada rama, pide solo los datos que esa figura necesita antes de calcular el área.

Entrada

figura (C/R) y radio o base+altura

Salida

area de la figura elegida

import java.util.Scanner;

public class AreaFigura {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce C (círculo) o R (rectángulo): ");
        char figura = Character.toUpperCase(sc.next().charAt(0));

        if (figura == 'C') {
            System.out.print("Introduce el radio: ");
            double radio = sc.nextDouble();
            double area = Math.PI * Math.pow(radio, 2);
            System.out.println("El área del círculo es: " + area);
        } else if (figura == 'R') {
            System.out.print("Introduce la base: ");
            double base = sc.nextDouble();
            System.out.print("Introduce la altura: ");
            double altura = sc.nextDouble();
            double area = base * altura;
            System.out.println("El área del rectángulo es: " + area);
        } else {
            System.out.println("Opción no válida");
        }
        sc.close();
    }
}

Lógica: selectivas encadenadas (if - else if - else) sobre una variable de tipo char, convertida a mayúscula con Character.toUpperCase() para aceptar también "c" o "r". Cada rama pide únicamente los datos que necesita esa figura y aplica su propia fórmula: Math.PI * radio² para el círculo (usando la constante Math.PI) o base * altura para el rectángulo. Una tercera rama controla entradas no válidas.

Ejercicio 12 — Minutos entre dos horas

Pedir la introducción de una hora de comienzo (hora y minutos por separado) y una hora de fin (hora y minutos por separado) y visualiza los minutos que separan una hora de otra. Visualiza los mensajes de error oportunos ante posibles errores.

Pista: convierte cada hora a minutos totales (hora*60 + minutos) antes de restar. No olvides validar primero que las horas y minutos estén en su rango (0-23 y 0-59) usando el operador ||.

Entrada

horaIni, minIni, horaFin, minFin

Salida

diferencia (minutos) o mensaje de error

import java.util.Scanner;

public class MinutosEntreHoras {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Hora de inicio (0-23): ");
        int horaIni = sc.nextInt();
        System.out.print("Minutos de inicio (0-59): ");
        int minIni = sc.nextInt();
        System.out.print("Hora de fin (0-23): ");
        int horaFin = sc.nextInt();
        System.out.print("Minutos de fin (0-59): ");
        int minFin = sc.nextInt();

        if (horaIni < 0 || horaIni > 23 || horaFin < 0 || horaFin > 23
                || minIni < 0 || minIni > 59 || minFin < 0 || minFin > 59) {
            System.out.println("Error: hora o minutos fuera de rango");
        } else {
            int totalIni = horaIni * 60 + minIni;
            int totalFin = horaFin * 60 + minFin;

            if (totalFin < totalIni) {
                System.out.println("Error: la hora de fin es anterior a la de inicio");
            } else {
                int diferencia = totalFin - totalIni;
                System.out.println("Minutos transcurridos: " + diferencia);
            }
        }
        sc.close();
    }
}

Lógica: la clave es convertir cada hora a "minutos totales desde medianoche" (hora * 60 + minutos) para poder restarlas directamente. Antes de calcular se valida el rango de cada dato con el operador lógico ||, y después se comprueba que la hora de fin no sea anterior a la de inicio.

Ejercicio 13 — Área de un triángulo con validación

Leer base y altura de un triángulo y escribir el área siempre que los 2 datos sean positivos. Visualizar un mensaje de error si alguno de los 2 datos es negativo o 0.

Pista: la fórmula del área es (base * altura) / 2, pero antes debes comprobar con || que ninguno de los dos valores sea menor o igual que 0.

Entrada

base, altura del triángulo

Salida

area o mensaje de error

import java.util.Scanner;

public class AreaTriangulo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce la base del triángulo: ");
        double base = sc.nextDouble();
        System.out.print("Introduce la altura del triángulo: ");

Ejercicio 14 — Salario semanal de un obrero

Si trabaja 40 horas o menos se le paga 16€ por hora. Si trabaja más de 40 horas se le paga 16€ por cada una de las primeras 40 horas y 20€ por cada hora extra. El número de horas trabajadas se introduce por teclado.

Pista: separa las horas en dos tramos: hasta 40 horas a 16€/hora, y las horas que superen las 40 a 20€/hora cada una. Suma ambos tramos.

Entrada

horas trabajadas (por teclado)

Salida

salario semanal

import java.util.Scanner;

public class SalarioObrero {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce las horas trabajadas: ");
        double horas = sc.nextDouble();
        double salario;

        if (horas <= 40) {
            salario = horas * 16;
        } else {
            salario = 40 * 16 + (horas - 40) * 20;

        sc.close();
    }
}

Lógica: si no se superan las 40 horas, se paga todo a tarifa normal; si se superan, se separan las 40 horas normales (a 16€) de las horas extra (a 20€) y se suman ambas partes.

Ejercicio 15 — Descuento por compra de camisas

Si se compran tres camisas o más se aplica un descuento del 20% sobre el total de la compra; si son menos de tres camisas, un descuento del 10%. Se introduce por teclado el número de camisas y el precio (valen todas igual).

Pista: calcula primero el total sin descuento (numCamisas * precio) y después decide, según el número de camisas, qué porcentaje restarle a ese total.

numCamisas, precioUnidad

total a pagar, con descuento aplicado

import java.util.Scanner;

Ejercicio 16 — Juego de las tres preguntas

Se formulan tres preguntas SI/NO, una tras otra. Si se responde mal a cualquiera de ellas ya no se pregunta la siguiente y termina el juego. Si se aciertan las tres, se visualiza "Usted ha ganado".

Pista: anida las preguntas: solo formula la siguiente dentro del if de la anterior. Compara los String con equals() o equalsIgnoreCase(), nunca con ==. Ojo con cuál es la respuesta correcta de cada pregunta según el enunciado (Colón sí descubrió América, pero París no es capital de Bélgica).

Entrada

resp1, resp2, resp3 (SI/NO)

Salida

"Usted ha ganado" o fin anticipado del juego

import java.util.Scanner;

public class JuegoPreguntas {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.println("¿Colón descubrió América? (SI/NO)");
        String resp1 = sc.next();

        if (resp1.equalsIgnoreCase("SI")) {
            System.out.println("¿Es París capital de Bélgica? (SI/NO)");
            String resp2 = sc.next();

            if (resp2.equalsIgnoreCase("NO")) {
                System.out.println("¿Los Beatles era un grupo de rock americano? (SI/NO)");
                String resp3 = sc.next();

                if (resp3.equalsIgnoreCase("NO")) {
                    System.out.println("Usted ha ganado");
                } else {
                    System.out.println("Respuesta incorrecta. Fin del juego.");
                }
            } else {
                System.out.println("Respuesta incorrecta. Fin del juego.");
            }
        } else {
            System.out.println("Respuesta incorrecta. Fin del juego.");
        }
        sc.close();
    }
}

Lógica: las tres preguntas se anidan una dentro del bloque if de la anterior. Así, la siguiente pregunta solo se formula si la anterior se respondió correctamente. Los textos se comparan con equalsIgnoreCase(), no con ==. La respuesta correcta a la segunda pregunta es "NO" (París es capital de Francia) y a la tercera también "NO" (eran un grupo británico).

Ejercicio 17 — Deporte según la temperatura

Leer una temperatura y escribir qué deporte es apropiado: Natación (>85ºF), Tenis (70-85ºF), Golf (32-70ºF), Esquí (10-32ºF), Deportes de interior (≤10ºF).

Pista: ordena las comparaciones de mayor a menor temperatura con if - else if encadenados. Al llegar a un tramo ya sabes que los anteriores fallaron, así que solo hace falta comprobar el límite inferior de ese tramo.

Entrada

temp (temperatura en ºF)

Salida

Deporte recomendado

import java.util.Scanner;

public class DeporteTemperatura {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce la temperatura (ºF): ");
        double temp = sc.nextDouble();

        if (temp > 85) {
            System.out.println("Deporte recomendado: Natación");
        } else if (temp > 70) {
            System.out.println("Deporte recomendado: Tenis");
        } else if (temp > 32) {
            System.out.println("Deporte recomendado: Golf");
        } else if (temp > 10) {
            System.out.println("Deporte recomendado: Esquí");
        } else {
            System.out.println("Deporte recomendado: Deportes de interior");
        }
        sc.close();
    }
}

Lógica: "escalera" de if - else if que evalúa los rangos de mayor a menor temperatura. Como cada else ya asume que la condición anterior era falsa, basta con comparar el límite inferior de cada tramo.
