Cómo funciona Java por dentro

Java no compila directamente a código máquina: compila a un formato intermedio (bytecode) que ejecuta la JVM. Por eso el mismo programa corre en cualquier sistema.

1
Escribir
Archivo .java con tu código fuente.
2
Compilar
javac revisa toda la sintaxis y los tipos.
3
Bytecode
Se genera un .class, no específico de tu PC.
4
JVM
La máquina virtual interpreta el bytecode.
5
Resultado
Salida por consola.

Java compila el proyecto entero de una vez: por eso no existe un "link" entre tus archivos.

Anatomía de un programa

public class Main {
    public static void main(String[] args) {
        System.out.println("Hola mundo");   // equivale al cout de C++
    }
}

Todo vive en una clase

No hay código suelto como en Python o JS. La ejecución arranca en main.

Nombre de archivo

La clase pública Main va en Main.java. Deben coincidir exactamente.

Punto y coma

Obligatorio al final de cada instrucción, sin excepción.

Llaves {}

Delimitan los bloques; la indentación es solo por legibilidad.

Entrada de datos: Scanner

import java.util.Scanner;

Scanner sc = new Scanner(System.in);
String nombre = sc.nextLine();   // línea completa
int edad = sc.nextInt();         // entero
double n = sc.nextDouble();      // decimal

import solo hace falta para clases que NO son tuyas (librería estándar). Tus propias clases del mismo proyecto se ven entre sí sin importar nada.

Trampa: nextInt() + nextLine()

nextInt() no consume el salto de línea del Enter. Si después llamas a nextLine(), devuelve una cadena vacía. Solución: añadir un sc.nextLine(); extra para limpiarlo (igual que mezclar cin >> con getline en C++).

Clases y objetos

Una clase es el plano de una casa; un objeto es una casa real construida con ese plano. Con un solo plano puedes construir muchas casas, cada una con sus propios valores.

public class Coche {
    private String marca;               // atributos: lo que el coche TIENE
    private String modelo;
    private int velocidad;

    public Coche(String marca, String modelo) {   // constructor
        this.marca = marca;
        this.modelo = modelo;
        this.velocidad = 0;
    }

    public void acelerar(int cantidad) {          // método: lo que el coche HACE
        this.velocidad += cantidad;
    }

    public void frenar(int cantidad) {
        if (cantidad > this.velocidad) {
            this.velocidad = 0;
        } else {
            this.velocidad -= cantidad;
        }
    }
}

Atributos

Variables que guardan el estado de cada objeto. Cada objeto tiene su propia copia.

Constructor

Se llama igual que la clase y NO lleva tipo de retorno (ni void). Se ejecuta con new.

Métodos

void si solo hacen algo; si devuelven un valor, el tipo debe coincidir con el return.

this

"El objeto actual". Obligatorio solo cuando un parámetro tiene el mismo nombre que el atributo.

Usar la clase desde otra

public class Ejercicio6 {
    public static void main(String[] args) {
        Coche c1 = new Coche("Skoda", "Karoq");
        c1.acelerar(8);
        c1.frenar(6);
    }
}

¿Dónde va el main? Solo en la clase que quieres ejecutar (punto de entrada). Las clases "modelo" (Coche, Persona...) no llevan main: se usan desde otra. El nombre Main no es especial; Java busca cualquier clase con método main.

Herencia

Lo común se escribe una vez en la clase padre; las hijas lo heredan con extends y añaden lo propio.

public class Animal {
    protected String nombre;
    public Animal(String nombre) { this.nombre = nombre; }
    public void comer() { System.out.println(nombre + " está comiendo."); }
}

public class Perro extends Animal {
    public Perro(String nombre) {
        super(nombre);                  // primera línea obligatoria
    }
    public void ladrar() { System.out.println(nombre + " dice: ¡Guau!"); }
}

Qué pasa con new Perro("Rex")

1. Constructor de PerroRecibe "Rex" en su parámetro.
↓
2. super(nombre)Reenvía ese valor al constructor de la clase padre.
↓
3. Constructor de AnimalEjecuta this.nombre = nombre: aquí se guarda realmente el dato.
↓
4. Vuelve a PerroTermina el resto de su constructor. El objeto ya puede usar comer() y ladrar().

Polimorfismo

Una clase hija puede redefinir un método heredado con @Override. Si no lo redefine, conserva el del padre.

public class Moto extends Vehiculo {
    @Override
    public void arrancar() {
        System.out.println(marca + " arranca con un rugido.");
    }
}

Vehiculo v = new Moto("Kawasaki");
v.arrancar();     // versión de Moto: manda el objeto real, no el tipo de la variable

Regla clave: Java ejecuta el método según el tipo real del objeto (lo de la derecha de new), no según el tipo con el que se declaró la variable. Por eso un mismo bucle puede tratar objetos distintos de forma uniforme.

ArrayList

nombres.add("Ana");

nombres.get(0);            // "Ana"

nombres.size();            // 1

ArrayList<Figura> figuras = new ArrayList<>();    // con polimorfismo:
figuras.add(new Circulo("c1"));                     // hijas distintas en
figuras.add(new Rectangulo("r1"));                  // la misma lista

Excepciones: try / catch

try {
    int r = 10 / n;                              // puede fallar al ejecutar
    System.out.println(r);
} catch (ArithmeticException e) {
    System.out.println("No se puede dividir por cero.");
}
// el programa continúa aquí en vez de crashear

Usa if / else cuando...

Tú controlas la condición y la conoces de antemano (ej: saldo insuficiente).

Usa try / catch cuando...

El fallo viene de algo externo o impredecible (input del usuario, conversiones de texto).

Excepciones habituales: ArithmeticException (dividir por 0), InputMismatchException (texto en nextInt(), de java.util), NumberFormatException (Integer.parseInt("abc")).

Errores típicos (y cómo leerlos)

Falta el punto y coma

Mensaje: ';' expected. IntelliJ subraya la línea en rojo.

Getter con void

Un método que hace return no puede ser void: public double getSaldo(). El tipo antes del nombre debe coincidir con lo que devuelve.

Variable "sombra": compila pero da 0

Escribir double base = sc.nextDouble(); crea una variable local nueva que tapa al atributo. Para asignar al atributo, sin tipo delante: base = sc.nextDouble();.

possible lossy conversion from double to int

Intentas guardar un double en un int y perderías decimales. Cambia el tipo de la variable a double, o fuerza con casting (int) 5.7 solo si de verdad quieres truncar.

Tipo equivocado en el ArrayList

ArrayList<Circulo> solo acepta objetos Circulo: add("c1") no compila, hace falta add(new Circulo("c1")). Para mezclar hijas, declara la lista con el tipo padre.

Confundir constructor y método

Solo es constructor lo que se llama igual que la clase y se invoca con new. acelerar() o frenar() son métodos.

Ejercicio: CuentaBancaria

Clase con saldo privado, constructor con saldo inicial, depositar, retirar (rechaza si no hay saldo) y getter.

Mostrar solución 
public class CuentaBancaria {
    private double saldo;

    public CuentaBancaria(double saldoInicial) {
        this.saldo = saldoInicial;
    }

    public void depositar(double cantidad) {
        this.saldo += cantidad;
    }

    public void retirar(double cantidad) {
        if (cantidad > this.saldo) {
            System.out.println("Saldo insuficiente.");
        } else {
            this.saldo -= cantidad;
        }
    }

    public double getSaldo() {
        return this.saldo;
    }
}

Ejercicio: Figuras con polimorfismo

Figura con calcularArea() genérico; Circulo y Rectangulo lo sobreescriben. Recórrelos desde una única ArrayList<Figura>.

Mostrar solución 
public class Figura {
    protected String nombre;
    public Figura(String nombre) { this.nombre = nombre; }
    public void calcularArea() { System.out.println("Área no definida"); }
}

public class Circulo extends Figura {
    private double radio;
    public Circulo(String nombre, double radio) {
        super(nombre);
        this.radio = radio;
    }
    @Override
    public void calcularArea() {
        System.out.println(Math.PI * radio * radio);
    }
}

public class Rectangulo extends Figura {
    private double base, altura;
    public Rectangulo(String nombre, double base, double altura) {
        super(nombre);
        this.base = base;
        this.altura = altura;
    }
    @Override
    public void calcularArea() {
        System.out.println(base * altura);
    }
}

// En el main:
ArrayList<Figura> figuras = new ArrayList<>();
figuras.add(new Circulo("c1", 2));
figuras.add(new Rectangulo("r1", 3, 4));
for (Figura f : figuras) { f.calcularArea(); }
