Ejercicio 1 — Valor absoluto de un número

Leer un número y escribir el valor absoluto del mismo.

Pista: piensa en el signo del número. Con una única estructura Si-SiNo puedes decidir si hay que cambiarle el signo o dejarlo tal cual.

Entrada

num (número real introducido por teclado)

Salida

abs (valor absoluto de num)

Algoritmo ValorAbsoluto
    Definir num, abs Como Real

    Escribir "Introduce un número:"
    Leer num

    Si num < 0 Entonces
        abs <- -num
    SiNo
        abs <- num
    FinSi

    Escribir "El valor absoluto es: ", abs
FinAlgoritmo

Lógica: es la estructura selectiva más simple. Si num es negativo, se invierte su signo con -num; si ya es positivo o cero, se deja igual. La condición num < 0 es el único punto de decisión del algoritmo.

Ejercicio 7 — Coste de una llamada telefónica

Pista: usa un Si-SiNo: una rama para menos de 3 minutos (coste fijo) y otra para el resto. En esa segunda rama, ¿cuántos minutos "de más" hay sobre los 3 primeros?

duracion (minutos de la llamada)

Ejercicio 9 — Ecuación de segundo grado

Resolver la ecuación cuadrática ax²+bx+c=0. Si la operación dentro de la raíz es inferior a 0, visualizar "La solución son dos números complejos conjugados". Si el divisor es 0, visualizar "Error: División entre 0".

Pista: primero comprueba si a = 0 (evita dividir entre 0). Después calcula el discriminante (b² - 4ac) en una variable intermedia y decide según su signo antes de aplicar SQRT().

Entrada

a, b, c (coeficientes)

Salida

x1, x2 o mensaje de error / complejas

Algoritmo EcuacionCuadratica
    Definir a, b, c Como Real
    Definir discriminante, x1, x2 Como Real

    Escribir "Introduce el coeficiente a:"
    Leer a
    Escribir "Introduce el coeficiente b:"
    Leer b
    Escribir "Introduce el coeficiente c:"
    Leer c

    Si a = 0 Entonces
        Escribir "Error: División entre 0"
    SiNo
        discriminante <- b^2 - 4*a*c

        Si discriminante < 0 Entonces
            Escribir "La solución son dos números complejos conjugados"
        SiNo
            x1 <- (-b + SQRT(discriminante)) / (2*a)
            x2 <- (-b - SQRT(discriminante)) / (2*a)
            Escribir "x1 = ", x1
            Escribir "x2 = ", x2
        FinSi
    FinSi
FinAlgoritmo

Lógica: usa selectivas anidadas. La primera comprueba que a no sea 0 (evita dividir entre 0 en la fórmula). La segunda, ya dentro, evalúa el discriminante: si es negativo no existe raíz real (soluciones complejas); si es ≥ 0 se calculan x1 y x2 con la fórmula general, usando discriminante como variable intermedia para no repetir el cálculo.

Ejercicio 10 — Día de la semana

Programa que permita ingresar un número de 1 a 7 y visualice el correspondiente día de la semana (1 Lunes, 2 Martes, etc). Si el número introducido no está comprendido entre 1 y 7 visualizar "Error: valor fuera de rango".

Pista: con siete valores concretos que comparar sobre la misma variable, la estructura Según-Hacer es más clara que encadenar siete Si. No olvides el caso De Otro Modo.

Entrada

dia (número entero 1-7)

Salida

Nombre del día o mensaje de error

Algoritmo DiaSemana
    Definir dia Como Entero

    Escribir "Introduce un número del 1 al 7:"
    Leer dia

    Según dia Hacer
        1: Escribir "Lunes"
        2: Escribir "Martes"
        3: Escribir "Miércoles"
        4: Escribir "Jueves"
        5: Escribir "Viernes"
        6: Escribir "Sábado"
        7: Escribir "Domingo"

            Escribir "Error: valor fuera de rango"
    FinSegún
FinAlgoritmo

Lógica: en lugar de encadenar siete Si-SiNo, se usa la estructura selectiva múltiple Según-Hacer, ideal cuando una misma variable se compara con varios valores concretos. La cláusula De Otro Modo cubre cualquier valor fuera de 1-7.

Ejercicio 11 — Área de círculo o rectángulo

Programa que calcule el área, bien de un círculo, bien de un rectángulo. Pedirá que se introduzca C o R. Si se introdujo C, pedir el radio y visualizar área. Si se introdujo R, pedir base y altura y visualizar área.

Pista: primero decide qué figura es (compara con "C" o "R") y, dentro de cada rama, pide solo los datos que esa figura necesita antes de calcular el área.

Entrada

figura (C/R) y radio o base+altura

Salida

area de la figura elegida

Algoritmo AreaFigura
    Definir figura Como Caracter
    Definir radio, base, altura, area Como Real

    Escribir "Introduce C (círculo) o R (rectángulo):"
    Leer figura

    Si figura = "C" Entonces
        Escribir "Introduce el radio:"
        Leer radio
        area <- PI * radio^2
        Escribir "El área del círculo es: ", area
    SiNo
        Si figura = "R" Entonces
            Escribir "Introduce la base:"
            Leer base
            Escribir "Introduce la altura:"
            Leer altura
            area <- base * altura
            Escribir "El área del rectángulo es: ", area
        SiNo
            Escribir "Opción no válida"
        FinSi
    FinSi
FinAlgoritmo

Lógica: selectivas anidadas sobre una variable de tipo Caracter. Cada rama pide únicamente los datos que necesita esa figura y aplica su propia fórmula: PI * radio² para el círculo (usando la constante PI de PSeInt) o base * altura para el rectángulo. Una tercera rama controla entradas no válidas.

Ejercicio 12 — Minutos entre dos horas

Pedir la introducción de una hora de comienzo (hora y minutos por separado) y una hora de fin (hora y minutos por separado) y visualiza los minutos que separan una hora de otra. Visualiza los mensajes de error oportunos ante posibles errores.

Pista: convierte cada hora a minutos totales (hora*60 + minutos) antes de restar. No olvides validar primero que las horas y minutos estén en su rango (0-23 y 0-59) usando el operador O.

Entrada

horaIni, minIni, horaFin, minFin

Salida

diferencia (minutos) o mensaje de error

Algoritmo MinutosEntreHoras
    Definir horaIni, minIni, horaFin, minFin Como Entero
    Definir totalIni, totalFin, diferencia Como Entero

    Escribir "Hora de inicio (0-23):"
    Leer horaIni
    Escribir "Minutos de inicio (0-59):"
    Leer minIni
    Escribir "Hora de fin (0-23):"
    Leer horaFin
    Escribir "Minutos de fin (0-59):"
    Leer minFin

    Si horaIni < 0 O horaIni > 23 O horaFin < 0 O horaFin > 23 O minIni < 0 O minIni > 59 O minFin < 0 O minFin > 59 Entonces
        Escribir "Error: hora o minutos fuera de rango"
    SiNo
        totalIni <- horaIni * 60 + minIni
        totalFin <- horaFin * 60 + minFin

        Si totalFin < totalIni Entonces
            Escribir "Error: la hora de fin es anterior a la de inicio"
        SiNo
            diferencia <- totalFin - totalIni
            Escribir "Minutos transcurridos: ", diferencia
        FinSi
    FinSi
FinAlgoritmo

Lógica: la clave es convertir cada hora a "minutos totales desde medianoche" (hora * 60 + minutos) para poder restarlas directamente. Antes de calcular se valida el rango de cada dato con el operador lógico O, y después se comprueba que la hora de fin no sea anterior a la de inicio.

Ejercicio 13 — Área de un triángulo con validación

Leer base y altura de un triángulo y escribir el área siempre que los 2 datos sean positivos. Visualizar un mensaje de error si alguno de los 2 datos es negativo o 0.

Pista: la fórmula del área es (base * altura) / 2, pero antes debes comprobar con O que ninguno de los dos valores sea menor o igual que 0.

base, altura del triángulo

area o mensaje de error

    Escribir "Introduce la base del triángulo:"
    Leer base
    Escribir "Introduce la altura del triángulo:"

Ejercicio 14 — Salario semanal de un obrero

Si trabaja 40 horas o menos se le paga 16€ por hora. Si trabaja más de 40 horas se le paga 16€ por cada una de las primeras 40 horas y 20€ por cada hora extra. El número de horas trabajadas se introduce por teclado.

Pista: separa las horas en dos tramos: hasta 40 horas a 16€/hora, y las horas que superen las 40 a 20€/hora cada una. Suma ambos tramos.

Entrada

horas trabajadas (por teclado)

Salida

salario semanal

Algoritmo SalarioObrero
    Definir horas Como Real
    Definir salario Como Real

    Escribir "Introduce las horas trabajadas:"
    Leer horas

    Si horas <= 40 Entonces
        salario <- horas * 16
    SiNo
        salario <- 40 * 16 + (horas - 40) * 20
    FinSi

    Escribir "El salario semanal es: ", salario, "€"
FinAlgoritmo

Lógica: si no se superan las 40 horas, se paga todo a tarifa normal; si se superan, se separan las 40 horas normales (a 16€) de las horas extra (a 20€) y se suman ambas partes.

Ejercicio 15 — Descuento por compra de camisas

Si se compran tres camisas o más se aplica un descuento del 20% sobre el total de la compra; si son menos de tres camisas, un descuento del 10%. Se introduce por teclado el número de camisas y el precio (valen todas igual).

numCamisas, precioUnidad

Salida

total a pagar, con descuento aplicado

Algoritmo CompraCamisas

    Escribir "Número de camisas:"
    Leer numCamisas
    Escribir "Precio de cada camisa:"
    Leer precioUnidad

Lógica: primero se calcula el total bruto (secuencial), después la selectiva decide el porcentaje de descuento según la cantidad comprada, y por último se resta ese descuento del total.
