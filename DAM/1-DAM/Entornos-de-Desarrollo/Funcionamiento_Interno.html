Principales componentes y su funcionamiento

Programación · DAM 1º · Arquitectura del Software

Un computador está formado por un procesador (CPU), memoria principal y dispositivos de entrada/salida, conectados por medio de buses.

Procesador (CPU)

Ejecuta instrucciones y coordina el funcionamiento del sistema.

Unidad de control (CU)

Decodifica instrucciones y coordina el funcionamiento.

Reloj

Sincroniza todas las operaciones.

ALU

Realiza operaciones aritméticas y lógicas.

Banco de registros

Almacenan datos temporalmente durante la ejecución.

RegistroFunción
PCContador de programa
IRRegistro de instrucción
MAR/DMRegistro de direcciones
MDR/RMRegistro de memoria
SPPuntero de pila
Registro de estadoIndicadores de estado (flags)

Buses de comunicación

Conectan la CPU con la memoria y los periféricos, transportando direcciones, datos y señales de control.

Bus de direcciones

La CPU envía la dirección de memoria a la que quiere acceder.

Bus de datos

Transfiere instrucciones y datos. Es bidireccional.

Bus de control

Señales de control (lectura / escritura, etc.).

Memoria principal (RAM)

Almacena instrucciones y datos del programa que se está ejecutando. Se organiza en posiciones direccionables, y cada posición almacena una palabra (instrucción o dato).

DirecciónContenido (una palabra)

1Palabra 1

3Palabra 3
……
N − 1Palabra N − 1

Entrada / Salida (E/S)

Permite la comunicación del computador con el mundo exterior a través de los periféricos: dispositivos que permiten introducir datos, obtener resultados o almacenar información.

Dispositivos de entrada

Teclado, ratón.

Dispositivos de salida

Monitor, impresora.

Dispositivos de almacenamiento

Disco / SSD.

Ciclo de ejecución de una instrucción

La CPU repite continuamente estos pasos para ejecutar un programa.

1. Fase de búsqueda (captación)

  1. El PC contiene la dirección de la siguiente instrucción.
  2. Esa dirección se pasa al registro de direcciones y viaja por el bus de direcciones.
  3. La memoria devuelve la instrucción por el bus de datos.
  4. La instrucción se guarda en el IR y el PC se incrementa.

2. Fase de ejecución

  1. La unidad de control decodifica la instrucción.
  2. Si hace falta, se leen operandos de registros o memoria.
  3. La ALU opera, o se realiza lectura/escritura o E/S.
  4. Se guarda el resultado y se actualiza el registro de estado.

↻ Este ciclo se repite para cada instrucción del programa.
