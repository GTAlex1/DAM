# Apuntes de DAM

Bienvenido/a. Este es mi repositorio de apuntes del ciclo de **Desarrollo de Aplicaciones Multiplataforma**, organizado como si fuera un proyecto de código: una carpeta por curso, una subcarpeta por módulo, un archivo por tema.

## Cómo está organizado

```
content/
├── 1-DAM/
│   ├── Programacion/
│   ├── Bases-de-Datos/
│   ├── Sistemas-Informaticos/
│   ├── Lenguajes-de-Marcas/
│   └── Entornos-de-Desarrollo/
└── 2-DAM/
    ├── Acceso-a-Datos/
    ├── Desarrollo-de-Interfaces/
    ├── Programacion-Multimedia-y-Moviles/
    ├── Programacion-de-Servicios-y-Procesos/
    └── Sistemas-de-Gestion-Empresarial/
```

Abre cualquier archivo en el explorador de la izquierda para leerlo, igual que en VS Code.

## Cómo añadir un apunte nuevo

1. Crea el archivo `.md` dentro de la carpeta del módulo que corresponda.
2. Añade una entrada en `manifest.json` con su `name`, `type: "file"` y `path`.
3. Haz commit y push. GitHub Pages se actualiza solo.

> Tip: numera los archivos (`01-`, `02-`...) para que el orden del tema se mantenga en el árbol.
