Instalar Apuntes DAM

Se añade a tu pantalla de inicio y se abre como una app, sin la barra del navegador.

Este navegador (Opera o Firefox de escritorio) no permite instalar aplicaciones web. Abre Apuntes DAM en Chrome o Edge para instalarla desde ahí.

  1. Pulsa el botón Compartir (el cuadrado con la flecha hacia arriba).
  2. Desliza y elige Añadir a pantalla de inicio.
  3. Pulsa Añadir.
  1. Abre el menú del navegador (los tres puntos ⋮).
  2. Elige Instalar aplicación o Añadir a pantalla de inicio.
  3. Confirma con Instalar.
